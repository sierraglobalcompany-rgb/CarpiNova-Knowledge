# Política FigureSpec

Cada visual significativo se registra como FigureSpec con región fuente, propósito, entidades, etiquetas, relaciones, precisión geométrica, modo de reconstrucción y secuencia educativa cuando aplique. Los diagramas técnicos, tablas, cotas y QR deben preferir reconstrucción determinística; no se permite que una imagen generativa invente medidas. Los activos de terceros se marcan con su restricción de uso.
